## Quick-Reference: What Breaks on a Typical Revision Bump?

1. **Protocol revision** (`OSRS_PROTOCOL_REVISION` in `protocol.h`) — must match the new rev.
2. **Packet size tables** (`src/protocol.c:244-513`) — almost always need regeneration.
3. **Incoming/outgoing opcodes** (`protocol.h` lines 69-168) — often shift.
4. **Login CRC order** (`src/protocol.c:625-649`) — frequently changes.
5. **Platform stats block** (`src/protocol.c:587-617`) — may need new values if Jagex updates `vs.ag`.
6. **RSA modulus** (`src/rsa.c:17-21`) — rotates unpredictably; check `OSRS_RSA_MODULUS` env override for quick testing.
7. **Cache path / format** — rarely changes, but verify if loading fails after an update.
